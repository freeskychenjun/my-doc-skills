# 强制性条文检查

| 编号     | 名称            | 内容                                                                                                                                                                  |
| ------ | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mp_001 | 设计洪水计算过程检查    | 《水利水电工程设计洪水计算规范》1.0.9：对设计洪水计算过程中所依据的基本资料、计算方法及其主要环节，采用的各种参数和计算成果，应进行多方面分析检查，论证成果的合理性。                                                                               |
| mp_002 | 暴雨洪水潮位资料检查    | 《水利水电工程设计洪水计算规范》2.1.2：对计算设计洪水所依据的暴雨、洪水、潮位资料和流域、河道特征资料，应进行合理性检查；对水尺零点高程变动情况及大洪水年份的浮标系数、水面流速系数、推流借用断面情况等应重点检查和复核，必要时还应进行调查和比测。                                        |
| mp_003 | 洪水系列一致性检查     | 《水利水电工程设计洪水计算规范》2.2.1：洪水系列应具有一致性。当流域内因修建蓄水、引水、提水、分洪、滞洪等工程，大洪水时发生堤防溃决、溃坝等，明显改变了洪水过程，影响了洪水系列的一致性；或因河道整治、水尺零点高程系统变动影响水（潮）位系列一致性时，应将系列统一到同一基础。                          |
| mp_004 | 插补延长资料合理性检查   | 《水利水电工程设计洪水计算规范》2.3.5：对插补延长的洪水、暴雨和潮位资料，应进行多方面的分析论证，检查其合理性。                                                                                                          |
| mp_005 | 历史洪水暴雨潮位资料检查  | 《水利水电工程设计洪水计算规范》2.4.1：对搜集的历史洪水、潮位、暴雨资料及其汇编成果，应进行合理性检查；对历史洪水洪峰流量应进行复核，必要时应补充调查和考证；对近期发生的特大暴雨、洪水及特大潮，应进行调查。                                                           |
| mp_006 | 分期设计洪水重现期考证   | 《水利水电工程设计洪水计算规范》3.4.5：分期设计洪水计算时，历史洪水重现期应在分期内考证，其重现期不应短于在年最大洪水系列中的重现期。                                                                                               |
| mp_007 | 产流汇流参数率定      | 《水利水电工程设计洪水计算规范》4.3.1：由设计暴雨计算设计洪水或由可能最大暴雨计算可能最大洪水时，应充分利用设计流域或邻近地区实测的暴雨、洪水对应资料，对产流和汇流计算方法中的参数进行率定，并分析参数在大洪水时的特性及变化规律。参数率定与使用方法应一致；洪水过程线的分割与回加应一致。不同方法的产流和汇流参数不应任意移用。 |
| mp_008 | 设计暴雨洪水成果合理性检查 | 《水利水电工程设计洪水计算规范》4.3.7：由设计暴雨计算的设计洪水或由可能最大暴雨计算的可能最大洪水成果，应分别与本地区实测、调查的大洪水和设计洪水成果进行对比分析，以检查其合理性。                                                                        |
| mp_009 | 水文计算资料可靠性评价   | 《水利水电工程水文计算规范》2.2.1：水文计算依据的流域特征和水文测验、整编、调查资料应进行检查，对重要资料，应进行重点复核。对有明显错误或存在系统偏差的资料，应予改正并建档备查。对采用资料的可靠性，应作出评价。                                                         |
| mp_010 | 水位流量关系高程系统一致性 | 《水利水电工程水文计算规范》5.3.1：根据工程设计要求，拟定设计断面工程修建前天然河道的水位流量关系。水位高程系统应与工程设计采用的高程系统一致。                                                                                          |
| mp_011 | 水位流量关系曲线外延要求  | 《水利水电工程水文计算规范》5.3.7：水位流量关系曲线的高水外延，应利用实测大断面、洪水调查等资料，根据断面形态、河段水力特性，采用多种方法综合分析拟定。低水延长，应以断流水位控制。                                                                        |

# 常见设计问题检查

## 设计洪水

| 编号           | 名称          | 内容                   |
| ------------ | ----------- | -------------------- |
| ci_flood_001 | 设计洪水成果合理性分析 | 对于设计洪水成果，需有合理性分析相关内容 |

## 设计径流

| 编号            | 名称          | 内容                                               |
| ------------- | ----------- | ------------------------------------------------ |
| ci_runoff_001 | 径流设计参证站三性分析 | 径流设计成果的三性分析应对径流设计参证站（依据站）进行分析，而不是对水库坝址径流成果进行三性分析 |
| ci_runoff_002 | 水文比拟法修正方法   | 采用水文比拟法计算坝址设计径流时，径流修正用流域面雨量比值修正，而不是用径流深比值修正      |

## 水位流量关系

| 编号           | 名称             | 内容                                                               |
| ------------ | -------------- | ---------------------------------------------------------------- |
| ci_stage_001 | 无实测资料时水位流量关系拟定 | 对于水库工程设计中的水位流量关系，设计断面所在河段无实测水文资料时，应进行水文调查和临时测流，用多种方法综合拟定水位流量关系曲线 |
| ci_stage_002 | 利用洪痕分析水位流量关系   | 尽量利用调查洪痕，分析水位流量关系的合理性                                            |

## 水面线

| 编号           | 名称          | 内容                                                                               |
| ------------ | ----------- | -------------------------------------------------------------------------------- |
| ci_water_001 | 水面线计算影响因素说明 | 影响水面线计算成果的精度与可靠性主要有：断面测量资料、河段沿程各断面设计流量分配、河段糙率的分析采用、起推断面的设计水位等。因此报告中要对上述几项进行较详细说明 |
| ci_water_002 | 阻水建筑物壅水计算   | 在水面线计算中，若涉及拦河闸坝、桥梁等阻水建筑物，要有阻水建筑物基本情况介绍和壅水计算相关说明                                  |
| ci_water_003 | 水面线成果合理性分析  | 对水面线计算成果，需利用调查洪水水面线或洪痕点水位，分析设计洪水水面线成果的合理性                                        |

## 排涝

| 编号              | 名称        | 内容                                                                                                                                                                         |
| --------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ci_drainage_001 | 排涝模数合理性分析 | 对设计排涝流量要进行合理性分析：对于5年一遇排涝标准，农田涝区排涝模数一般在0.50～0.65m³/s·km²之间；10年一遇排涝标准，农田涝区排涝模数一般在0.70～0.90m³/s·km²之间，城镇涝区排涝模数一般在0.80～1.00m³/s·km²之间；20年一遇排涝标准，城镇涝区排涝模数一般在1.00～1.40m³/s·km²之间 |

# 文字规范性检查

| 编号      | 名称          | 内容                                                                                                                                                                   |
| ------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| std_001 | 大数值单位使用规范   | 数值较大的精确数字，可用亿、百万、万或10的8次方、10的6次方、10的4次方作单位，但同一本报告中只能采用一种形式                                                                                                           |
| std_002 | 符号名称与符号使用规范 | 报告中应注意符号名称与符号的正确使用。报告条文中不应用符号代替符号名称或文字说明，当带有阿拉伯数字时，应使用计量单位符号                                                                                                         |
| std_003 | 流量数值保留规范    | 流量数值保留3位有效数字，小数点后不超过3位，例如：1293应为1290；12应为12.0；1.1应为1.10；1.152应为1.15。                                                                                                 |
| std_004 | 工程等别和级别数字书写 | 工程中等别和级别的数字书写规定：1.水利水电枢纽工程的工程等别为罗马数字（Ⅰ、Ⅱ、Ⅲ、Ⅳ、Ⅴ、Ⅵ、Ⅶ等）；水工建筑物的级别为阿拉伯数字（1、2、3、4、5等）；2.内河航道及船闸等级为罗马数字（Ⅰ、Ⅱ、Ⅲ、Ⅳ、Ⅴ、Ⅵ、Ⅶ等）；3.围岩类别为罗马数字；岩石的可钻性级别为阿拉伯数字；4.岸坡阶地级别和地面水环境质量标准均为罗马数字 |

# 表格逻辑关系专项检查

| 编号      | 名称     | 内容                                                                                                                                                                                                  |
| ------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| tbl_001 | 统计值检查  | 针对表格中出现的统计值（最大值、最小值、平均值、合计值、小计值、百分比值），逐项验证其正确性。具体检查：1）行合计/列合计：各分项数值相加是否等于合计值；2）小计与总计：各小计之和是否等于总计；3）平均值：各分项数值的平均是否等于所列平均值；4）百分比/占比：各分项占比之和是否为100%，单项占比是否等于该项/合计；5）最大最小值：所标注的最大值是否确实是该行/列中的最大值，最小值同理。 |
| tbl_002 | 异常值检查  | 若表格中出现异常值，提醒用户检查合理性。                                                                                                                                                                                |
| tbl_003 | 逻辑关系检查 | 针对有明显逻辑关系的行间数据、列间数据，检查逻辑关系合理性。                                                                                                                                                                      |

# 检查结果输出要求

* 检查结果要与要求一一对应，不能有遗漏，即使某一项要求经检查全部符合，也要把主要分析结论输出

* 检查结果中需引用完整的各检查项要求，便于读者将检查结果和要求对比

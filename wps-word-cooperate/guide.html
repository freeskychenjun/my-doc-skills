wps-word-cooperate
在 WPS 里和 AI 一起改 Word

AI 直接在你已经打开的 WPS 文字里改文档——改动实时出现在窗口里，文字修改是修订，你能逐条接受或拒绝；排版、表格、题注、目录、批注、版式核对也能一并做。不重写文件、不改变版式、不悄悄改掉原文。

这是什么

它调的是 WPS 自己的自动化接口（COM），不是"读文件—改文件—写文件"。这带来三个直接好处：

文件开着也能改

不会因为"文件被占用"失败。已经打开的直接接着用，不会再开一份。

格式不会走样

排版由 WPS 自己做，存下来还是 WPS 的样子，不会被第三方库重写得面目全非。

你能边看边改

AI 每次动手前读到的都是文档当下的样子；你随时可以插手，它下次读到的是你改过的版本。

和"让 AI 写个脚本改 docx"的区别：脚本路线你看不到过程、文件开着还会写不进去、公式与版式会走样；这条路是让 WPS 自己动手，你在旁边看着。

装它

  1. 拷文件夹
    把整个 wps-word-cooperate 文件夹放到你的技能目录，通常是 C:\Users\<你的用户名>\.agents\skills\。
    也可以装进院里的 skill 管理平台。
  2. 确认有 WPS
    这台机器要装 WPS Office（文字组件即可）。微软 Office 也能用，会自动回退。
  3. 自检 
    powershell -NoProfile -ExecutionPolicy Bypass -File ^
  "C:\Users\<你>\.agents\skills\wps-word-cooperate\scripts\wps.ps1" doctor
    看到 wps.installed: true 就装好了。第一次跑会用系统自带的 csc.exe 编译一个约 1 秒的小程序，之后一直用缓存。
唯一依赖：.NET Framework 4.8（Windows 10/11 自带）+ WPS。不需要 Python，不需要装插件，不需要联网。

五分钟上手

最省事：直接跟 AI 说人话。

例子 1 · 润色并逐条看

「打开 D:\报告\某报告.docx，读一遍，把第 3 章里"大概 1234 m3/s"改成"约 1234 m³/s"，我能看着改。」

→ AI 以修订形式改动，你在 WPS 里接受/拒绝。

例子 2 · 校审批注

「按检查要点过一遍第 2 章，问题直接在原文对应段落加批注。」

→ 批注挂在具体字句上，右侧气泡可见。

例子 3 · 一键排版

「全文正文改成仿宋小四、1.5 倍行距、首行缩进 2 字符，标题 1 黑体三号居中，页脚加页码。」

→ 格式类改动不进修订，一次 Ctrl+Z 可整批撤回。

想自己调命令也简单（路径按你机器改）：

$s = "C:\Users\<你>\.agents\skills\wps-word-cooperate\scripts\wps.ps1"

powershell -NoProfile -ExecutionPolicy Bypass -File $s status
powershell -NoProfile -ExecutionPolicy Bypass -File $s open   -Doc "D:\报告\某报告.docx"
powershell -NoProfile -ExecutionPolicy Bypass -File $s read   -Doc "D:\报告\某报告.docx" -From 1 -Count 60
powershell -NoProfile -ExecutionPolicy Bypass -File $s revise -Doc "D:\报告\某报告.docx" -Items edits.json
powershell -NoProfile -ExecutionPolicy Bypass -File $s render -Doc "D:\报告\某报告.docx" -Page 1 -To 3 -Out "D:\报告\_pages"
powershell -NoProfile -ExecutionPolicy Bypass -File $s save   -Doc "D:\报告\某报告.docx"

edits.json 长这样（expect 是"这段开头的几个字"，用来保证改的位置没错）：

{"items":[
  {"para":12,"expect":"3.2 工程地质","op":"replace","find":"孔口高程","replace":"孔口地面高程"},
  {"para":15,"expect":"根据地质勘察","op":"set_text","text":"根据地质勘察成果，坝址区基岩为……"},
  {"para":31,"expect":"本阶段不再","op":"delete"}
]}

命令全景（27 条）

会话与自检

命令作用
doctor环境自检：哪个套件可用、版本、是否在跑、开着的文档、渲染能力、进程数
status在跑的实例与文档清单（路径 / 是否只读 / 是否已保存 / 段数）
open打开或复用；返回 readOnly、段落数、页数
close / quit关一份 / 关全部并退出（quit 会波及你开的其它文档，慎用）

读与改

命令作用
read段落（编号 · 样式 · 自动编号 · 文本 · 是否在表格里）+ 表格清单 + 页数/修订数/批注数
revise修订模式批量改写：replace（字符级）· set_text · insert_after · delete；先全量校验，有一条不符就一条不改
comment加批注（可锚到某几个字）；-Delete -Index N 删批注
insert批量插入段落（默认干净写入、不进修订；-Track 才留痕），可带样式与格式
cell改一个表格单元格的文字（可带字体字号对齐）

排版

命令作用
font整篇统一字体（正文、表格、页眉页脚、文本框一起换，中英文都换）
format整篇 / 一段 / 区间 / 某样式的所有段：字符格式 + 段落格式
style改样式本身（正文、标题 1…），所有用它的段落一起变；可顺带去掉自动编号
page纸张 / 方向 / 页边距 / 页眉页脚文字 / 页码（逐节）

表格、图表、目录

命令作用
table建表（grid/three-line/none 框线、表头跨页重复、列宽、行不跨页、表题）/ 改表
caption域式题注「表 1 / 图 1」，自动编号、题不落单
picture插图（可带图题）/ 调宽高 / 按百分比裁剪；缩太小会告警
toc插入并刷新目录域（依赖标题样式）
reference参考文献列表（悬挂缩进）/ 段末上标引用 [1,2,5]
audit机械检查：单位未用上标、重复词、括号混用、连续空格、全角数字、标题跳级、图表缺题注——返回段落号与建议，供判断后落批注
fields一键刷新全部域：页码、目录、题注、引用（改完正文、交付前跑一次）
view把窗口滚到某段/某页（不动光标）

协作交接

命令作用
revisions列出未处理的修订（类型/作者/所在段/文本），或按人要求接受/拒绝
snapshot存一份段落文本快照（给 diff 用，不写进文档目录）
diff和快照比：哪些段被改了（before→after）、哪些增删——人改的和 AI 改的都算
handoff在文档旁生成 .handoff.md 交接单：状态 / 待办 / 操作记录 / 变化表

看与存

命令作用
render把页面渲成 PNG 给 AI 核对版式（走打印视图的页面图元，不截图、不落 PDF）
save保存 / 另存（覆盖写同一个文件时保持 WPS 自己的格式）

-Size12 / "10.5pt"字号（磅）
-Bold -Italic -Underline开关关掉用 -Bold:$false
-Super -Sub开关上标 / 下标
-Color"#C00000"字体颜色
-Alignleft|center|right|justify中文也认 居左/居中/居右/两端对齐
-FirstLineIndent2 / "0.74cm" / 0首行缩进：纯数字＝字符数，带单位＝长度
-IndentChars2左缩进（按字符）
-LineSpacing1.5 / "20pt" / "at least 20pt" / single倍数 / 固定值 / 最小值
-SpaceBefore -SpaceAfter"6pt" / 0段前 / 段后

和人接力：这是它最该被用的方式

一套完整的交接只需要四个动作。下面是真实跑过的一轮（592 段、31 页的报告）：

  1. AI 开工前拍快照
    snapshot -Tag round1 —— 记下"我接手时文档长什么样"。
  2. AI 干活
    两处文字修订 + 一条批注，全部以修订形式留在文档里。
  3. 人裁决 / 手改
    人在 WPS 里接受了 1 处修订，并手改了另一段（"4 种"→"5种"）。
  4. AI 读结果继续
    revisions 看到待裁决 4→2 条；diff -Since round1 精确报出： 第 61 段（我的修订）、第 68 段（人被采纳的）、第 85 段（人手改的 4→5 种）。
    然后 handoff -Note "…" 在文档旁生成交接单。
关键在于 AI 不需要你把改了什么复述一遍，也不用把 592 段重读一遍——revisions 告诉你还剩多少待裁决，diff 告诉你文本变成了什么样。
一个必须记住的语义：WPS 里的文本是"接受视图"——插入的字临时算进去、删掉的字临时不算。所以
· 「还有多少待裁决」看 revisions
· 「文本最后长什么样」看 diff

一条通道（先守这条，再谈别的）

一旦这份文档在本 skill 手上（WPS 里开着），这次协作里就不要把它交给别的文档 skill：校审用 audit + comment -Items，润色用 revise，排版用 format / style / page。

原因不是体验，是会坏：那几个 skill 改的是磁盘文件，而这份文件正被 WPS 独占（实测写盘 PermissionError）；它们还产出副本，一改就分成两份内容不同的稿子。

例外：用户要「不动原件、出一份新稿」或「无人值守批量跑」——那就先 save、close，把文件交出去。

两套协作剧本

A · 批次式（推荐）

AI 一口气干完一段 → 人审 → AI 再接手第二轮。

snapshot → 批量改（修订）→ 请人处理 → diff + revisions 读结果 → 第二轮 → save → handoff

原则：一轮只做一类事（润色 / 排版 / 校审分开），人处理完再开下一轮；每轮开头都拍快照。

B · 并发式

你和 AI 同时在看同一份文档、来回交替。

① 写之前先看返回值里的 changedOutside；② expect 报 ANCHOR_MISSING 时先 read 那段——很可能是你改了它；③ 不替你裁决修订；④ 不动你的光标。

注意：感知是"轮次级"的——AI 只在下一条命令时才被告知"中间有人动过"，做不到实时跟随你打字。

实测坑（照做少返工）

现象原因与对策
表格 -Para 插表后位置很怪锚点段落若在表格里，会变成"往单元格里塞表"。read 里带 inTable: true 的段落会报错；要嵌表加 nested: true，否则换一个正文段。
插入的段落跑进了表格单元格锚点紧挨表格时可能发生；返回里 inTable: true 就是提示。要插在表格前，改用 -Where before 指向表格后那一段。
改了批注旁边的字，多出/少了 1 个字批注锚点占一个字符位置却不在 Range.Text 里。程序会先读回校验并自动纠正，纠正不了就拒绝执行；必要时先 comment -Delete 摘掉批注再改。
页码出现两套中文报告常在页眉编页码；page -PageNumber 是往页脚插。动手前先 render 看一眼，或干脆不传。
目录是空的 / 显示"错误！未找到目录项"文档里没有「标题 1/2/3」样式的段落。先用 style 或人工套标题样式。
截图里加粗看不出来WPS 的 EMF 渲图对 Bold 呈现不可靠，docx 里是对的——别据此判断没加粗。
图片里的字小得看不清插图时被缩得太小；picture 会返回 scale 和 warning，按提示重画或加宽。
标题文字本身带编号，样式又自动编号出现双重编号；用 style -NoNumbering 去掉自动的那个。

常见问题

错误码 / 现象怎么办
NO_APP没装 WPS 文字，或 COM 没注册。手动打开一次 WPS 再试。
NOT_OPEN路径和实际打开的不是同一个（另存过、短路径、相对路径）。先 status，把 path 原样复制。
READONLY文件被别处占用或只读。关掉占用的程序，或另存一份再改——不要强行覆盖。
ANCHOR_MISSING段落编号漂移 / 原文对不上 / 可能是人改了那段。整批一条都没改，重新 read 核对再来。
BUSY / TIMEOUT你正在打字，或有对话框挡着。关掉对话框，等几秒重试，别连发。
中文乱码用 powershell -File 调脚本（内部固定 UTF-8），别自己把 JSON 拼到命令行里。
wps.exe 变多中途异常没 close。先 status 看实例数，只结束无窗口的自动化实例，别按名字批量杀。
保存后文件发出去打不开单位透明加密：保存后 docx/PDF 落盘即密文（文件头 17DA5FA01633CD9A）。发之前先解密。

什么时候不要用它

  • 无人值守、上千段一次跑完的批量润色 → 用离线的 docx-paragraph-polish（不依赖 WPS，也不受加密影响）
  • 纯排版、不需要人看过程 → design-report-format
  • 只要一份检查报告、不改原文 → design-report-review
  • Excel / PPT → 这个 skill 只做 Word

边界与未验证

做不到的

  • 逐字写入动画、跟随滚动、右下角迷你卡片、无窗口静默实例——这些是宿主插件的能力，skill 没有窗口句柄
  • 并发的"实时感知"：只能在下一条命令时告诉你"中间有人动过"
  • 公式（LaTeX→原生）、流程图（形状+连线）、版面回填——参考实现有，这里没做

实测环境

  • WPS Office 12.1.0.29161（其它版本未验证）
  • 合成报告 306 段 / 29 页；真实报告 592 段 / 31 页，全流程跑过
  • 页眉页脚里的修订、旧 .doc 格式、SVG 插图未验证
  • 只核对过渲染图，没实际打印
